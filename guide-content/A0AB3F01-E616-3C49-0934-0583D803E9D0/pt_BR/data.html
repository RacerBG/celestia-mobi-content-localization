Os aplicativos de celestia.mobi oferecem o mesmo suporte a scripts e URLs que o Celestia para desktop.

Scripts

Favoritos → Scripts em dispositivos móveis e Arquivo → Scripts no desktop listam os scripts integrados e os da pasta pública, incluindo complementos de scripts baixados de celestia.mobi. Você também pode adicionar scripts manualmente. Consulte Usar complementos e scripts para saber como colocá-los nessa pasta.

O Celestia também pode abrir scripts diretamente. Encontre um arquivo .cel ou .celx no gerenciador de arquivos e escolha abri-lo com o Celestia.

URLs

URLs cel:// (favoritos)

As URLs cel:// (favoritos) salvam o estado do Celestia para que você possa voltar a ele depois. O gerenciador integrado fica no menu Favoritos no desktop e em Favoritos nos dispositivos móveis. Você também pode digitar uma URL cel:// na barra de endereços do navegador; o sistema deve oferecer abri-la no Celestia.

URLs celaddon:// e celguide://

celaddon:// e celguide:// são esquemas de URL dos aplicativos de celestia.mobi para abrir complementos ou artigos. Normalmente, os complementos usam celaddon://item?item=ADDON_ID e os artigos usam celguide://guide?guide=ARTICLE_ID.

URLs celestia://

celestia:// é um novo esquema de URL dos aplicativos de celestia.mobi para executar várias tarefas.

celestia://addon/ADDON_ID

Abre o complemento com o ADDON_ID informado.

celestia://article/ARTICLE_ID

Abre o artigo com o ARTICLE_ID informado.

celestia://object/OBJECT_PATH?action=ACTION

ACTION é opcional. Quando omitido, a URL abre a tela de informações do objeto indicado por OBJECT_PATH. ACTION pode ser select, go, center, follow, chase, track, syncOrbit, lock ou land.
