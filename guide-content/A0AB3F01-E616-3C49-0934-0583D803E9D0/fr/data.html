Les applications de celestia.mobi prennent en charge les scripts et les URL comme la version de bureau de Celestia.

Scripts

Favoris → Scripts sur mobile et Fichier → Scripts sur ordinateur répertorient les scripts intégrés et ceux du dossier public, notamment les extensions de scripts téléchargées sur celestia.mobi. Vous pouvez aussi y ajouter des scripts manuellement. Consultez Utiliser les extensions et les scripts pour savoir comment procéder.

Celestia peut aussi ouvrir directement des scripts. Recherchez un fichier .cel ou .celx dans votre gestionnaire de fichiers, puis choisissez de l’ouvrir avec Celestia.

URL

URL cel:// (signets)

Les URL cel:// (signets) enregistrent l’état de Celestia pour vous permettre d’y revenir plus tard. Le gestionnaire intégré est accessible dans le menu Signets sur ordinateur et dans Favoris sur mobile. Vous pouvez aussi saisir une URL cel:// dans la barre d’adresse du navigateur ; le système devrait proposer de l’ouvrir dans Celestia.

URL celaddon:// et celguide://

celaddon:// et celguide:// sont des schémas d’URL des applications de celestia.mobi permettant d’ouvrir des extensions ou des articles. Les extensions utilisent généralement celaddon://item?item=ADDON_ID et les articles celguide://guide?guide=ARTICLE_ID.

URL celestia://

celestia:// est un nouveau schéma d’URL des applications de celestia.mobi permettant d’effectuer diverses tâches.

celestia://addon/ADDON_ID

Ouvre l’extension correspondant à l’ADDON_ID indiqué.

celestia://article/ARTICLE_ID

Ouvre l’article correspondant à l’ARTICLE_ID indiqué.

celestia://object/OBJECT_PATH?action=ACTION

ACTION est facultatif. Sans ce paramètre, l’URL ouvre les informations de l’objet désigné par OBJECT_PATH. ACTION peut prendre les valeurs select, go, center, follow, chase, track, syncOrbit, lock et land.
