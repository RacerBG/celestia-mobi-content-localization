celestia.mobi의 앱은 데스크톱 Celestia와 동일하게 스크립트와 URL을 지원합니다.

스크립트

모바일의 즐겨찾기 → 스크립트와 데스크톱의 파일 → 스크립트에는 기본 제공 스크립트와 공개 폴더의 스크립트가 표시됩니다. celestia.mobi에서 받은 스크립트 애드온도 포함됩니다. 스크립트를 직접 추가할 수도 있습니다. 폴더에 넣는 방법은 애드온과 스크립트 사용하기를 참고하세요.

Celestia는 스크립트를 직접 열 수도 있습니다. 파일 관리자에서 .cel 또는 .celx 파일을 찾은 다음 Celestia로 열기를 선택하세요.

URL

cel:// URL(북마크)

cel:// URL(북마크)은 Celestia의 상태를 저장하여 나중에 다시 돌아갈 수 있게 합니다. 기본 북마크 관리자는 데스크톱의 북마크 메뉴와 모바일의 즐겨찾기에 있습니다. 브라우저 주소창에 cel:// URL을 입력하면 시스템이 Celestia에서 열도록 안내합니다.

celaddon:// 및 celguide:// URL

celaddon://와 celguide://는 celestia.mobi 앱에서 애드온이나 글을 여는 URL 스키마입니다. 일반적으로 애드온은 celaddon://item?item=ADDON_ID, 글은 celguide://guide?guide=ARTICLE_ID를 사용합니다.

celestia:// URL

celestia://는 celestia.mobi 앱에서 여러 작업을 수행하는 새로운 URL 스키마입니다.

celestia://addon/ADDON_ID

지정한 ADDON_ID의 애드온을 엽니다.

celestia://article/ARTICLE_ID

지정한 ARTICLE_ID의 글을 엽니다.

celestia://object/OBJECT_PATH?action=ACTION

ACTION은 선택 사항입니다. 생략하면 OBJECT_PATH로 지정한 천체의 정보 화면을 엽니다. ACTION에는 select, go, center, follow, chase, track, syncOrbit, lock, land를 사용할 수 있습니다.
