celestia.mobi 的应用与桌面版 Celestia 一样，支持脚本和 URL。

脚本

移动版的收藏 → 脚本和桌面版的文件 → 脚本会列出内置脚本与公共文件夹中的脚本，包括从 celestia.mobi 下载的脚本插件。也可以手动添加脚本。有关如何放入公共文件夹，请参考使用插件和脚本。

Celestia 也可以直接打开脚本。在文件管理器中找到 .cel 或 .celx 文件，并选择用 Celestia 打开。

URL

cel:// URL（书签）

cel:// URL（书签）保存 Celestia 的状态，方便日后返回。内置书签管理器位于桌面版的书签菜单和移动版的收藏中。也可以在浏览器地址栏输入 cel:// URL，系统会提示用 Celestia 打开。

celaddon:// 和 celguide:// URL

celaddon:// 和 celguide:// 是 celestia.mobi 应用用于打开插件或文章的 URL 协议。插件通常使用 celaddon://item?item=ADDON_ID，文章使用 celguide://guide?guide=ARTICLE_ID。

celestia:// URL

celestia:// 是 celestia.mobi 应用用于执行各种任务的新 URL 协议。

celestia://addon/ADDON_ID

打开指定 ADDON_ID 的插件。

celestia://article/ARTICLE_ID

打开指定 ARTICLE_ID 的文章。

celestia://object/OBJECT_PATH?action=ACTION

ACTION 是可选参数。省略时，URL 会打开 OBJECT_PATH 指定天体的信息页面。ACTION 可取 select、go、center、follow、chase、track、syncOrbit、lock 和 land。
