Las aplicaciones de celestia.mobi ofrecen el mismo soporte para scripts y URL que Celestia de escritorio.

Scripts

Favoritos → Scripts en dispositivos móviles y Archivo → Scripts en el escritorio muestran los scripts integrados y los de la carpeta pública, incluidos los complementos de scripts descargados de celestia.mobi. También puedes añadir scripts manualmente. Consulta Usar complementos y scripts para saber cómo colocarlos en esa carpeta.

Celestia también puede abrir scripts directamente. Busca un archivo .cel o .celx en tu explorador de archivos y elige abrirlo con Celestia.

URL

URL cel:// (marcadores)

Las URL cel:// (marcadores) guardan el estado de Celestia para que puedas volver a él más adelante. El gestor integrado se encuentra en el menú Marcadores del escritorio y en Favoritos en dispositivos móviles. También puedes introducir una URL cel:// en la barra de direcciones del navegador; el sistema debería ofrecer abrirla en Celestia.

URL celaddon:// y celguide://

celaddon:// y celguide:// son esquemas de URL de las aplicaciones de celestia.mobi para abrir complementos o artículos. Normalmente los complementos usan celaddon://item?item=ADDON_ID y los artículos celguide://guide?guide=ARTICLE_ID.

URL celestia://

celestia:// es un nuevo esquema de URL de las aplicaciones de celestia.mobi para realizar distintas tareas.

celestia://addon/ADDON_ID

Abre el complemento con el ADDON_ID indicado.

celestia://article/ARTICLE_ID

Abre el artículo con el ARTICLE_ID indicado.

celestia://object/OBJECT_PATH?action=ACTION

ACTION es opcional. Si se omite, la URL abre la vista de información del objeto indicado por OBJECT_PATH. ACTION puede ser select, go, center, follow, chase, track, syncOrbit, lock o land.
