celestia.mobi のアプリは、デスクトップ版 Celestia と同様にスクリプトと URL に対応しています。

スクリプト

モバイル版の「お気に入り → スクリプト」、デスクトップ版の「ファイル → スクリプト」には、組み込みスクリプトと公開フォルダ内のスクリプトが表示されます。celestia.mobi からダウンロードしたスクリプトアドオンも含まれます。手動で追加することもできます。配置方法はアドオンとスクリプトを使うを参照してください。

スクリプトを直接開くこともできます。ファイル管理アプリで .cel または .celx ファイルを探し、Celestia で開くことを選んでください。

URL

cel:// URL（ブックマーク）

cel:// URL（ブックマーク）は Celestia の状態を保存し、後からその状態に戻れるようにします。組み込みの管理機能は、デスクトップ版では「ブックマーク」、モバイル版では「お気に入り」にあります。ブラウザのアドレスバーに cel:// URL を入力して、Celestia で開くこともできます。

celaddon:// と celguide:// の URL

celaddon:// と celguide:// は、celestia.mobi のアプリでアドオンや記事を開く URL スキームです。通常、アドオンは celaddon://item?item=ADDON_ID、記事は celguide://guide?guide=ARTICLE_ID を使います。

celestia:// URL

celestia:// は、celestia.mobi のアプリで各種操作を行う新しい URL スキームです。

celestia://addon/ADDON_ID

指定した ADDON_ID のアドオンを開きます。

celestia://article/ARTICLE_ID

指定した ARTICLE_ID の記事を開きます。

celestia://object/OBJECT_PATH?action=ACTION

ACTION は省略可能です。省略すると、OBJECT_PATH で指定した天体の情報画面を開きます。ACTION には select、go、center、follow、chase、track、syncOrbit、lock、land を指定できます。
