Le applicazioni di celestia.mobi supportano script e URL come la versione desktop di Celestia.

Script

Preferiti → Script sui dispositivi mobili e File → Script sul desktop mostrano gli script integrati e quelli nella cartella pubblica, inclusi i componenti aggiuntivi di script scaricati da celestia.mobi. Puoi aggiungerne anche manualmente. Consulta Usare componenti aggiuntivi e script per sapere come inserirli nella cartella.

Celestia può aprire gli script anche direttamente. Cerca un file .cel o .celx nel gestore di file e scegli di aprirlo con Celestia.

URL

URL cel:// (segnalibri)

Gli URL cel:// (segnalibri) salvano lo stato di Celestia per permetterti di tornarci in seguito. Il gestore integrato è nel menu Segnalibri sul desktop e in Preferiti sui dispositivi mobili. Puoi anche inserire un URL cel:// nella barra degli indirizzi del browser; il sistema dovrebbe proporre di aprirlo in Celestia.

URL celaddon:// e celguide://

celaddon:// e celguide:// sono schemi URL delle applicazioni di celestia.mobi per aprire componenti aggiuntivi o articoli. In genere i componenti aggiuntivi usano celaddon://item?item=ADDON_ID e gli articoli celguide://guide?guide=ARTICLE_ID.

URL celestia://

celestia:// è un nuovo schema URL delle applicazioni di celestia.mobi per eseguire varie operazioni.

celestia://addon/ADDON_ID

Apre il componente aggiuntivo con l’ADDON_ID indicato.

celestia://article/ARTICLE_ID

Apre l’articolo con l’ARTICLE_ID indicato.

celestia://object/OBJECT_PATH?action=ACTION

ACTION è facoltativo. Se omesso, l’URL apre le informazioni dell’oggetto indicato da OBJECT_PATH. ACTION può essere select, go, center, follow, chase, track, syncOrbit, lock o land.
