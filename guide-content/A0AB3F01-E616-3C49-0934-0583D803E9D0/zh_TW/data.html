celestia.mobi 的 App 與桌面版 Celestia 一樣，支援指令碼和 URL。

指令碼

行動版的喜好項目 → 指令碼和桌面版的檔案 → 指令碼會列出內建指令碼與公用資料夾中的指令碼，包括從 celestia.mobi 下載的指令碼附加元件。也可以手動加入指令碼。放入公用資料夾的方法請參考使用附加元件與指令碼。

Celestia 也可以直接開啟指令碼。在檔案管理程式中找到 .cel 或 .celx 檔案，並選擇用 Celestia 開啟。

URL

cel:// URL（書籤）

cel:// URL（書籤）儲存 Celestia 的狀態，方便日後返回。內建書籤管理員位於桌面版的書籤選單和行動版的喜好項目中。也可以在瀏覽器網址列輸入 cel:// URL，系統會提示以 Celestia 開啟。

celaddon:// 與 celguide:// URL

celaddon:// 與 celguide:// 是 celestia.mobi App 用來開啟附加元件或文章的 URL 配置。附加元件通常使用 celaddon://item?item=ADDON_ID，文章使用 celguide://guide?guide=ARTICLE_ID。

celestia:// URL

celestia:// 是 celestia.mobi App 用來執行各種工作的全新 URL 配置。

celestia://addon/ADDON_ID

開啟指定 ADDON_ID 的附加元件。

celestia://article/ARTICLE_ID

開啟指定 ARTICLE_ID 的文章。

celestia://object/OBJECT_PATH?action=ACTION

ACTION 是選填參數。省略時，URL 會開啟 OBJECT_PATH 指定天體的資訊頁面。ACTION 可使用 select、go、center、follow、chase、track、syncOrbit、lock 和 land。
