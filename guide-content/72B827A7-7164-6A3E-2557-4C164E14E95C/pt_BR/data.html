O Celestia oferece suporte completo a controles de jogo. Quando seu dispositivo é pareado com um controle compatível, o Celestia começa a receber seus comandos automaticamente, sem exigir nenhuma ação (no Win32, você pode usar F8 para ativar ou desativar o controle por controle de jogo).

Enquanto a versão original do Celestia para Win32 usa apenas um número limitado de botões (veja aqui), o Celestia no Android/iOS/macOS/Windows(UWP) adiciona uma camada de personalização que permite usar mais botões. Você pode encontrá-los em Configurações -> Controle de jogo (no Windows: Arquivo -> Configurações -> Controle de jogo).

Botões

Você pode atribuir uma ação a cada botão listado nas configurações. O botão Menu/Selecionar fica reservado para exibir o menu.
