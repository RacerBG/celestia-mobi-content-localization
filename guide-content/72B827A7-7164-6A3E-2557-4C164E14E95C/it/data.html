Celestia supporta pienamente i controller di gioco. Quando il dispositivo è abbinato a un controller supportato, Celestia ne riceve automaticamente gli input senza richiedere alcuna azione (su Win32 è possibile usare F8 per attivare o disattivare il controllo tramite controller).

Mentre la versione originale di Celestia per Win32 usa solo un numero limitato di pulsanti (vedere qui), Celestia su Android/iOS/macOS/Windows(UWP) aggiunge possibilità di personalizzazione che consentono di usare più pulsanti. Si trovano in Impostazioni -> Controller di gioco (su Windows: File -> Impostazioni -> Controller di gioco).

Pulsanti

È possibile assegnare un’azione a ciascun pulsante elencato nelle impostazioni. Il pulsante Menu/Selezione resta riservato alla visualizzazione del menu.

Levette analogiche

Le levette analogiche servono per beccheggiare verso l’alto/il basso e imbardare a sinistra/destra. Se necessario, è possibile invertirle nelle impostazioni.
