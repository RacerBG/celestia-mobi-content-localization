Celestia полностью поддерживает игровые контроллеры. При сопряжении устройства с поддерживаемым контроллером Celestia автоматически начинает получать его команды без дополнительных действий (на Win32 клавиша F8 включает или выключает управление контроллером).

В то время как исходная версия Celestia для Win32 использует лишь ограниченное число кнопок (см. здесь), Celestia на Android/iOS/macOS/Windows(UWP) добавляет настройки, позволяющие задействовать больше кнопок. Они доступны в разделе Настройки -> Игровой контроллер (на Windows: Файл -> Настройки -> Игровой контроллер).

Кнопки

Каждой кнопке из списка в настройках можно назначить действие. Кнопка «Меню/Выбор» остаётся зарезервированной для открытия меню.

Например, можно настроить и применить приведённые ниже назначения, чтобы получить управление, более похожее на другие игры с поддержкой контроллеров.

Аналоговые стики

Аналоговые стики управляют тангажом вверх/вниз и рысканием влево/вправо. При необходимости их можно инвертировать в настройках.
