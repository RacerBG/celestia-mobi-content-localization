Celestia es totalmente compatible con los mandos de juego. Cuando el dispositivo se empareja con un mando compatible, Celestia empieza a recibir sus entradas automáticamente sin que tenga que hacer nada (en Win32 puede usar F8 para activar o desactivar el control con mando).

Mientras que la versión original de Celestia para Win32 solo utiliza un número limitado de botones (consulte aquí), Celestia en Android/iOS/macOS/Windows(UWP) añade una capa de personalización que permite utilizar más botones. Puede encontrarlos en Ajustes -> Mando de juego (en Windows: Archivo -> Ajustes -> Mando de juego).

Botones

Puede asignar una acción a cada botón de la lista de ajustes. El botón Menú/Seleccionar se reserva para mostrar el menú.

Por ejemplo, puede personalizar y aplicar los ajustes siguientes para obtener una experiencia más parecida a la de otros juegos compatibles con mandos.

Palancas analógicas

Las palancas analógicas se usan para cabecear arriba/abajo y guiñar a izquierda/derecha. Puede invertirlas en los ajustes si es necesario.
