Les extensions sont créées par des membres de la communauté Celestia, qui ne participent pas nécessairement au développement du logiciel. Leur création ne demande pas de connaissances approfondies en programmation. Vous aussi, vous pouvez en créer !

Consulter le wiki

Tutoriels de création d’extensions pour débutants constitue un bon point de départ. Vous y découvrirez les principes de base et ce que les extensions permettent de modifier dans Celestia.

Partir d’une extension existante

Une fois les formats de fichiers de Celestia compris, il est conseillé de commencer par modifier une extension existante. Téléchargez-en une dans l’application et suivez Utiliser les extensions et les scripts pour trouver son emplacement. Modifiez quelques champs qui vous intéressent, puis relancez l’application pour vérifier le résultat.

Points importants

  1. Utilisez un format de texture pris en charge. Par exemple, les images .heic de l’appareil photo de l’iPhone doivent d’abord être converties.
  2. Vérifiez la résolution des textures. Leurs dimensions doivent être des puissances de 2, comme 1024x1024 ou 1024x2048. Tous les appareils ne prennent pas en charge les autres dimensions.
  3. Vérifiez le format des fichiers de catalogue, notamment que tous les délimiteurs sont correctement appariés.
  4. Vérifiez les noms de fichiers. Évitez les caractères spéciaux dans les noms de fichiers et de dossiers.
  5. Les références aux fichiers, par exemple à une texture dans un catalogue, doivent respecter exactement les majuscules et minuscules du nom d’origine. C’est indispensable sur les systèmes de fichiers sensibles à la casse.

Partager votre extension

Compressez votre extension dans une archive ZIP ; seul le format .zip est accepté. Vous pouvez ensuite l’envoyer dans les catégories d’extensions de l’application avec celestia-addon-validator.
