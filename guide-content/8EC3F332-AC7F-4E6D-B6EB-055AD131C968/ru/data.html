Дополнения создают участники сообщества Celestia, которые не обязательно являются разработчиками программы. Для этого не нужны глубокие знания программирования. Вы тоже можете создать дополнение!

Прочитайте вики

Руководства по созданию дополнений для начинающих — хорошая отправная точка. Они знакомят с основами создания дополнений и объясняют, что с их помощью можно изменить в Celestia.

Начните с готового дополнения

Разобравшись в форматах файлов Celestia, попробуйте изменить готовое дополнение. Загрузите его в приложении и прочитайте Использование дополнений и скриптов, чтобы найти папку установки. Измените несколько интересующих вас параметров в файлах и снова запустите приложение, чтобы проверить результат.

Важные замечания

  1. Используйте поддерживаемый формат текстур. Например, фотографии .heic с камеры iPhone не поддерживаются: их нужно предварительно преобразовать.
  2. Проверьте разрешение текстур. Размеры сторон должны быть степенями двойки, например 1024x1024 или 1024x2048. Другие размеры поддерживаются не на всех устройствах.
  3. Проверьте оформление файлов каталогов, например правильность парных скобок.
  4. Проверьте имена файлов. Избегайте специальных символов в именах файлов и папок.
  5. Ссылки на файлы, например на текстуру в каталоге, должны точно совпадать с исходным именем, включая регистр букв. Это необходимо для поиска на файловых системах, различающих регистр.

Поделитесь дополнением

Упакуйте дополнение в ZIP-архив: поддерживается только .zip. С помощью celestia-addon-validator его можно загрузить в категории дополнений приложения.
