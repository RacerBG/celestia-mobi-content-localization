Celestia permet une personnalisation complète. Vous pouvez remplacer le dossier depuis lequel les données sont chargées.

Sur toutes les plateformes, commencez par télécharger une copie du dossier de données de la version correspondante de Celestia.

  1. Téléchargez ici le dossier de données d’origine correspondant à votre version de l’application.
  2. Modifiez le dossier et le fichier celestia.cfg.

Ensuite…

Android

  1. Copiez le dossier sur l’appareil dans Android/data/space.celestia.mobilecelestia/files ou Android/media/space.celestia.mobilecelestia. Renommez-le au besoin pour éviter un conflit avec le dossier CelestiaResources par défaut.
  2. Lancez Celestia et ouvrez Réglages -> Emplacement des données.
  3. Choisissez l’emplacement du dossier de données (CelestiaResources) et du fichier de configuration (celestia.cfg).
  4. Fermez Celestia, puis relancez l’application.

iOS/iPadOS/macOS (Catalyst)

  1. Copiez le dossier à l’emplacement de votre choix sur l’appareil.
  2. Lancez Celestia et ouvrez Réglages -> Emplacement des données.
  3. Choisissez l’emplacement du dossier de données (CelestiaResources) et du fichier de configuration (celestia.cfg).
  4. Fermez Celestia, puis relancez l’application.

macOS (ancienne version)

  1. Copiez le dossier à l’emplacement de votre choix sur l’appareil.
  2. Lancez Celestia et ouvrez, dans la barre des menus, Celestia -> Changer le fichier de configuration.
  3. Choisissez l’emplacement du dossier de données (CelestiaResources) et du fichier de configuration (celestia.cfg).
  4. Cliquez sur « Confirmer et relancer ». Vous devez toutefois relancer l’application vous-même.

Windows (Microsoft Store)

Pour la version 2.1.18.0 ou ultérieure, procédez ainsi :

  1. Copiez le dossier à l’emplacement de votre choix sur l’appareil.
  2. Lancez Celestia et ouvrez Fichier -> Réglages -> Emplacement des données.
  3. Choisissez l’emplacement du dossier de données (CelestiaResources) et du fichier de configuration (celestia.cfg).
  4. Fermez Celestia, puis relancez l’application.

Pour les versions antérieures :

  1. Renommez CelestiaResources en Override.
  2. Lancez Celestia et choisissez Fichier -> Ouvrir le dossier personnalisé.
  3. Le gestionnaire de fichiers devrait s’ouvrir. Copiez-y le dossier Override.
  4. Fermez Celestia, puis relancez l’application.

Si les fichiers de configuration et de données sont correctement préparés, Celestia devrait charger vos fichiers.
