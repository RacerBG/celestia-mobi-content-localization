Celestia 支援完整的資料自訂。你可以變更讀取資料的目錄。

所有平台都需要先下載對應 Celestia 版本的資料目錄副本。

  1. 在這裡下載與 App 版本對應的原始資料目錄。
  2. 修改目錄內容和 celestia.cfg 檔案。

接著……

Android

  1. 將目錄複製到裝置上的 Android/data/space.celestia.mobilecelestia/files 或 Android/media/space.celestia.mobilecelestia 中。如有需要，請重新命名，避免與預設的 CelestiaResources 目錄同名。
  2. 執行 Celestia，開啟設定 -> 資料位置。
  3. 選擇資料目錄（CelestiaResources）和設定檔（celestia.cfg）的位置。
  4. 關閉 Celestia 並重新執行。

iOS/iPadOS/macOS（Catalyst）

  1. 將目錄複製到裝置上的任意位置。
  2. 執行 Celestia，開啟設定 -> 資料位置。
  3. 選擇資料目錄（CelestiaResources）和設定檔（celestia.cfg）的位置。
  4. 關閉 Celestia 並重新執行。

macOS（舊版）

  1. 將目錄複製到裝置上的任意位置。
  2. 執行 Celestia，在選單列選擇 Celestia -> 變更設定檔。
  3. 選擇資料目錄（CelestiaResources）和設定檔（celestia.cfg）的位置。
  4. 點選「確認並重新啟動」。請注意，需要自行重新執行 App。

Windows（Microsoft Store）

若使用 2.1.18.0 或更新版本，請依照以下步驟操作：

  1. 將目錄複製到裝置上的任意位置。
  2. 執行 Celestia，開啟檔案 -> 設定 -> 資料位置。
  3. 選擇資料目錄（CelestiaResources）和設定檔（celestia.cfg）的位置。
  4. 關閉 Celestia 並重新執行。

更早版本的操作方式：

  1. 將 CelestiaResources 重新命名為 Override。
  2. 執行 Celestia，選擇檔案 -> 開啟自訂資料夾。
  3. 檔案管理程式會開啟，將 Override 目錄複製進去。
  4. 關閉 Celestia 並重新執行。

若設定檔和資料檔案設定正確，Celestia 應該會載入你的檔案。
