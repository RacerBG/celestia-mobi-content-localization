Celestia permette una personalizzazione completa. Puoi sostituire la cartella da cui legge i dati.

Su tutte le piattaforme, scarica prima una copia della cartella dei dati della versione corrispondente di Celestia.

  1. Scarica qui la cartella dei dati originale della tua versione dell’app.
  2. Modifica la cartella e il file celestia.cfg.

Poi…

Android

  1. Copia la cartella sul dispositivo in Android/data/space.celestia.mobilecelestia/files o Android/media/space.celestia.mobilecelestia. Rinominala se necessario per evitare conflitti con la cartella predefinita CelestiaResources.
  2. Avvia Celestia e apri Impostazioni -> Posizione dei dati.
  3. Scegli la posizione della cartella dei dati (CelestiaResources) e del file di configurazione (celestia.cfg).
  4. Chiudi Celestia e riavvialo.

iOS/iPadOS/macOS (Catalyst)

  1. Copia la cartella in una posizione qualsiasi sul dispositivo.
  2. Avvia Celestia e apri Impostazioni -> Posizione dei dati.
  3. Scegli la posizione della cartella dei dati (CelestiaResources) e del file di configurazione (celestia.cfg).
  4. Chiudi Celestia e riavvialo.

macOS (versione classica)

  1. Copia la cartella in una posizione qualsiasi sul dispositivo.
  2. Avvia Celestia e apri nella barra dei menu Celestia -> Cambia file di configurazione.
  3. Scegli la posizione della cartella dei dati (CelestiaResources) e del file di configurazione (celestia.cfg).
  4. Premi «Conferma e riavvia». Ricorda che devi riavviare l’app personalmente.

Windows (Microsoft Store)

Per la versione 2.1.18.0 e successive, segui questi passaggi:

  1. Copia la cartella in una posizione qualsiasi sul dispositivo.
  2. Avvia Celestia e apri File -> Impostazioni -> Posizione dei dati.
  3. Scegli la posizione della cartella dei dati (CelestiaResources) e del file di configurazione (celestia.cfg).
  4. Chiudi Celestia e riavvialo.

Per le versioni precedenti:

  1. Rinomina CelestiaResources in Override.
  2. Avvia Celestia e scegli File -> Apri cartella personalizzata.
  3. Si aprirà il gestore di file. Copia lì la cartella Override.
  4. Chiudi Celestia e riavvialo.

Se i file di configurazione e dei dati sono impostati correttamente, Celestia dovrebbe caricare i tuoi file.
