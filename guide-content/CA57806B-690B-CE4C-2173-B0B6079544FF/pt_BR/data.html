O Celestia permite personalização completa. Você pode substituir a pasta de onde ele lê os dados.

Em todas as plataformas, primeiro baixe uma cópia da pasta de dados da versão correspondente do Celestia.

  1. Baixe aqui a pasta de dados original da sua versão do aplicativo.
  2. Modifique a pasta e o arquivo celestia.cfg.

Depois…

Android

  1. Copie a pasta para o dispositivo, dentro de Android/data/space.celestia.mobilecelestia/files ou Android/media/space.celestia.mobilecelestia. Renomeie-a se necessário para evitar conflito com a pasta padrão CelestiaResources.
  2. Execute o Celestia e abra Configurações -> Localização dos dados.
  3. Escolha a localização da pasta de dados (CelestiaResources) e do arquivo de configuração (celestia.cfg).
  4. Feche o Celestia e execute-o novamente.

iOS/iPadOS/macOS (Catalyst)

  1. Copie a pasta para qualquer local no dispositivo.
  2. Execute o Celestia e abra Configurações -> Localização dos dados.
  3. Escolha a localização da pasta de dados (CelestiaResources) e do arquivo de configuração (celestia.cfg).
  4. Feche o Celestia e execute-o novamente.

macOS (versão clássica)

  1. Copie a pasta para qualquer local no dispositivo.
  2. Execute o Celestia e abra, na barra de menus, Celestia -> Alterar arquivo de configuração.
  3. Escolha a localização da pasta de dados (CelestiaResources) e do arquivo de configuração (celestia.cfg).
  4. Clique em «Confirmar e reiniciar». Observe que você precisa reiniciar o aplicativo por conta própria.

Windows (Microsoft Store)

Para a versão 2.1.18.0 ou posterior, siga estas etapas:

  1. Copie a pasta para qualquer local no dispositivo.
  2. Execute o Celestia e abra Arquivo -> Configurações -> Localização dos dados.
  3. Escolha a localização da pasta de dados (CelestiaResources) e do arquivo de configuração (celestia.cfg).
  4. Feche o Celestia e execute-o novamente.

Para versões anteriores:

  1. Renomeie CelestiaResources para Override.
  2. Execute o Celestia e escolha Arquivo -> Abrir pasta personalizada.
  3. O explorador de arquivos será aberto. Copie a pasta Override para esse local.
  4. Feche o Celestia e execute-o novamente.

Se os arquivos de configuração e dados estiverem corretos, o Celestia deverá carregar seus arquivos.
