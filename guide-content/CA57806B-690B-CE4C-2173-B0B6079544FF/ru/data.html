Celestia позволяет полностью настроить данные. Можно изменить папку, из которой они загружаются.

На всех платформах сначала загрузите копию папки данных соответствующего выпуска Celestia.

  1. Загрузите исходную папку данных для вашей версии приложения здесь.
  2. Измените папку и файл celestia.cfg.

Затем…

Android

  1. Скопируйте папку на устройство в Android/data/space.celestia.mobilecelestia/files или Android/media/space.celestia.mobilecelestia. При необходимости переименуйте её, чтобы избежать совпадения с именем стандартной папки CelestiaResources.
  2. Запустите Celestia и откройте Настройки -> Расположение данных.
  3. Выберите расположение папки данных (CelestiaResources) и файла конфигурации (celestia.cfg).
  4. Закройте Celestia и запустите снова.

iOS/iPadOS/macOS (Catalyst)

  1. Скопируйте папку в любое место на устройстве.
  2. Запустите Celestia и откройте Настройки -> Расположение данных.
  3. Выберите расположение папки данных (CelestiaResources) и файла конфигурации (celestia.cfg).
  4. Закройте Celestia и запустите снова.

macOS (старая версия)

  1. Скопируйте папку в любое место на устройстве.
  2. Запустите Celestia и откройте в строке меню Celestia -> Изменить файл конфигурации.
  3. Выберите расположение папки данных (CelestiaResources) и файла конфигурации (celestia.cfg).
  4. Нажмите «Подтвердить и перезапустить». Учтите, что перезапустить приложение нужно самостоятельно.

Windows (Microsoft Store)

Для версии 2.1.18.0 и новее выполните следующие действия:

  1. Скопируйте папку в любое место на устройстве.
  2. Запустите Celestia и откройте Файл -> Настройки -> Расположение данных.
  3. Выберите расположение папки данных (CelestiaResources) и файла конфигурации (celestia.cfg).
  4. Закройте Celestia и запустите снова.

Для более ранних версий:

  1. Переименуйте CelestiaResources в Override.
  2. Запустите Celestia и выберите Файл -> Открыть пользовательскую папку.
  3. Откроется файловый менеджер. Скопируйте в него папку Override.
  4. Закройте Celestia и запустите снова.

Если файлы конфигурации и данных подготовлены правильно, Celestia должна загрузить ваши файлы.
