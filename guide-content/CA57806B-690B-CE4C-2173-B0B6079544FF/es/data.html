Celestia admite una personalización completa. Puedes sustituir el directorio del que lee los datos.

En todas las plataformas, primero debes descargar una copia del directorio de datos de la versión correspondiente de Celestia.

  1. Descarga aquí el directorio de datos original de tu versión de la aplicación.
  2. Modifica el directorio y el archivo celestia.cfg.

Después…

Android

  1. Copia el directorio al dispositivo dentro de Android/data/space.celestia.mobilecelestia/files o Android/media/space.celestia.mobilecelestia. Cámbiale el nombre si es necesario para evitar conflictos con el directorio predeterminado CelestiaResources.
  2. Ejecuta Celestia y abre Ajustes -> Ubicación de datos.
  3. Selecciona la ubicación del directorio de datos (CelestiaResources) y del archivo de configuración (celestia.cfg).
  4. Cierra Celestia y vuelve a ejecutarlo.

iOS/iPadOS/macOS (Catalyst)

  1. Copia el directorio a cualquier ubicación del dispositivo.
  2. Ejecuta Celestia y abre Ajustes -> Ubicación de datos.
  3. Selecciona la ubicación del directorio de datos (CelestiaResources) y del archivo de configuración (celestia.cfg).
  4. Cierra Celestia y vuelve a ejecutarlo.

macOS (versión clásica)

  1. Copia el directorio a cualquier ubicación del dispositivo.
  2. Ejecuta Celestia y abre en la barra de menús Celestia -> Cambiar archivo de configuración.
  3. Selecciona la ubicación del directorio de datos (CelestiaResources) y del archivo de configuración (celestia.cfg).
  4. Pulsa «Confirmar y reiniciar». Ten en cuenta que debes reiniciar la aplicación por tu cuenta.

Windows (Microsoft Store)

Si utilizas la versión 2.1.18.0 o posterior, sigue estos pasos:

  1. Copia el directorio a cualquier ubicación del dispositivo.
  2. Ejecuta Celestia y abre Archivo -> Ajustes -> Ubicación de datos.
  3. Selecciona la ubicación del directorio de datos (CelestiaResources) y del archivo de configuración (celestia.cfg).
  4. Cierra Celestia y vuelve a ejecutarlo.

Para versiones anteriores:

  1. Cambia el nombre de CelestiaResources a Override.
  2. Ejecuta Celestia y selecciona Archivo -> Abrir carpeta personalizada.
  3. Se abrirá el explorador de archivos. Copia allí el directorio Override.
  4. Cierra Celestia y vuelve a ejecutarlo.

Si los archivos de configuración y datos están correctamente preparados, Celestia debería cargar tus archivos.
