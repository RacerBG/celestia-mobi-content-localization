Celestia は完全なカスタマイズにも対応しています。データの読み込み元フォルダを変更できます。

どのプラットフォームでも、まず対応する Celestia リリースのデータフォルダをダウンロードします。

  1. アプリのバージョンに対応する元のデータフォルダをこちらからダウンロードします。
  2. フォルダと celestia.cfg ファイルを編集します。

続いて…

Android

  1. フォルダを端末の Android/data/space.celestia.mobilecelestia/files または Android/media/space.celestia.mobilecelestia 内にコピーします。標準の CelestiaResources と名前が重複しないよう、必要に応じて変更してください。
  2. Celestia を起動し、設定 -> データの場所を開きます。
  3. データフォルダ（CelestiaResources）と設定ファイル（celestia.cfg）の場所を選びます。
  4. Celestia を終了して再起動します。

iOS/iPadOS/macOS（Catalyst）

  1. フォルダを端末内の任意の場所にコピーします。
  2. Celestia を起動し、設定 -> データの場所を開きます。
  3. データフォルダ（CelestiaResources）と設定ファイル（celestia.cfg）の場所を選びます。
  4. Celestia を終了して再起動します。

macOS（従来版）

  1. フォルダを端末内の任意の場所にコピーします。
  2. Celestia を起動し、メニューバーの Celestia -> 設定ファイルを変更を開きます。
  3. データフォルダ（CelestiaResources）と設定ファイル（celestia.cfg）の場所を選びます。
  4. 「確認して再起動」を押します。ただし、アプリの再起動は手動で行う必要があります。

Windows（Microsoft Store）

2.1.18.0 以降では、次の手順を行います。

  1. フォルダを端末内の任意の場所にコピーします。
  2. Celestia を起動し、ファイル -> 設定 -> データの場所を開きます。
  3. データフォルダ（CelestiaResources）と設定ファイル（celestia.cfg）の場所を選びます。
  4. Celestia を終了して再起動します。

それ以前のバージョンでは：

  1. CelestiaResources の名前を Override に変更します。
  2. Celestia を起動し、ファイル -> カスタムフォルダを開くを選びます。
  3. ファイル管理画面が開くので、Override フォルダをその中にコピーします。
  4. Celestia を終了して再起動します。

設定ファイルとデータが正しく配置されていれば、Celestia がそれらを読み込みます。
