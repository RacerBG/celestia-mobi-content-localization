Celestia 支持完整的数据自定义。你可以更改读取数据的目录。

所有平台都需要先下载对应 Celestia 版本的数据目录副本。

  1. 在这里下载与你的应用版本对应的原始数据目录。
  2. 修改目录内容和 celestia.cfg 文件。

然后……

Android

  1. 将目录复制到设备上的 Android/data/space.celestia.mobilecelestia/files 或 Android/media/space.celestia.mobilecelestia 下。如有需要，请重命名，避免与默认的 CelestiaResources 目录重名。
  2. 运行 Celestia，打开设置 -> 数据位置。
  3. 选择数据目录（CelestiaResources）和配置文件（celestia.cfg）的位置。
  4. 关闭 Celestia 并重新运行。

iOS/iPadOS/macOS（Catalyst）

  1. 将目录复制到设备上的任意位置。
  2. 运行 Celestia，打开设置 -> 数据位置。
  3. 选择数据目录（CelestiaResources）和配置文件（celestia.cfg）的位置。
  4. 关闭 Celestia 并重新运行。

macOS（旧版）

  1. 将目录复制到设备上的任意位置。
  2. 运行 Celestia，在菜单栏中选择 Celestia -> 更改配置文件。
  3. 选择数据目录（CelestiaResources）和配置文件（celestia.cfg）的位置。
  4. 点击“确认并重新启动”。请注意，需要自行重新运行应用。

Windows（Microsoft Store）

如果使用 2.1.18.0 或更高版本，请按以下步骤操作：

  1. 将目录复制到设备上的任意位置。
  2. 运行 Celestia，打开文件 -> 设置 -> 数据位置。
  3. 选择数据目录（CelestiaResources）和配置文件（celestia.cfg）的位置。
  4. 关闭 Celestia 并重新运行。

对于更早版本：

  1. 将 CelestiaResources 重命名为 Override。
  2. 运行 Celestia，选择文件 -> 打开自定义文件夹。
  3. 文件管理器会打开，将 Override 目录复制进去。
  4. 关闭 Celestia 并重新运行。

如果配置和数据文件设置正确，Celestia 应该会加载你的文件。
