Dans Contrôle de la caméra -> Mode de vol, ou Navigation -> Mode de vol sous Windows, vous pouvez choisir différents modes de vol ou référentiels pour modifier vos déplacements dans Celestia.

Vol libre

Ce mode ne nécessite ni objet de référence ni objet cible. Vous pouvez voler librement sans être lié à un objet. Appuyez sur Échap pour l’activer.

Suivre

Ce mode nécessite un objet de référence et conserve votre position relative à l’objet sélectionné. C’est le mode par défaut de la commande « Aller à ».

Orbite synchronisée

Ce mode est semblable à « Suivre », mais synchronise aussi l’orbite de l’observateur autour de l’objet avec la rotation de celui-ci.

Verrouillage de phase

Ce mode nécessite un objet de référence et un objet cible. Il les lie dans l’espace : vous conservez votre position par rapport aux deux, même lorsqu’ils se déplacent.

Poursuivre

Ce mode est semblable au verrouillage de phase, mais vous n’indiquez qu’un objet. Le second est son objet parent.
