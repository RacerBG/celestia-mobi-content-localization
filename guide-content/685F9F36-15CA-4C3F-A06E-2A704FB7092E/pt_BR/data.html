Aqui você encontra respostas às perguntas mais frequentes sobre o Celestia. O Celestia também tem uma página no Wikilivros com recursos adicionais.

Como amplio o conteúdo do Celestia?

O Celestia permite usar complementos, que são conteúdos criados pela comunidade para enriquecer o Celestia. Para saber onde encontrá-los e como usá-los, consulte Usar complementos e scripts.

Como altero a configuração ou os dados do Celestia?

Você não pode alterar diretamente o arquivo celestia.cfg nem a pasta de dados padrão, porque a pasta do pacote do aplicativo não permite gravação nas versões modernas do Celestia. Porém, você pode seguir Pasta de dados personalizada para iniciar o Celestia com seu próprio arquivo celestia.cfg e pasta de dados no lugar dos padrões.

Quero criar meus próprios complementos. Por onde começo?

Consulte Criar um complemento para aprender a criar seus próprios complementos.

Como faço para baixar todos os complementos disponíveis no celestia.mobi?

O Celestia não oferece uma maneira de baixar vários complementos de uma vez, e também não recomendamos tentar fazer isso.
Alguns complementos podem entrar em conflito com outros e impedir que o Celestia inicie ou funcione corretamente. Ter complementos demais também deixa o Celestia muito mais lento.

Como relato erros nos dados do Celestia ou no aplicativo?

Se você notar erros em um complemento, abra uma issue em celestiamobile/celestia-addon-validator.
Se o erro estiver nos dados incluídos no Celestia, e não em um complemento, abra uma issue em CelestiaProject/CelestiaContent.
Para relatar um problema no programa, use «Enviar feedback» → «Relatar um bug» ou «Ajuda» → «Relatar um bug» dentro do aplicativo.

Por que não encontro determinado objeto astronômico no Celestia?

Os dados do aplicativo Celestia não estão atualizados, e esse geralmente é o motivo pelo qual um objeto mencionado nas notícias não aparece. A comunidade pode ter criado um complemento para o objeto; confira os complementos disponíveis on-line. Além disso, a busca do Celestia só procura estrelas, objetos do céu profundo e objetos do sistema mais próximo. Talvez você precise viajar primeiro até o sistema do objeto.

Como acesso a pasta de complementos no Android 11 ou posterior?

Por padrão, os complementos são instalados em Android/data, e o Android 11 dificulta o acesso dos gerenciadores de arquivos a essa pasta. Porém, o Celestia 1.7.8 ou posterior permite usar Android/media como pasta padrão dos complementos.
Para mudar a pasta, vá a «Configurações» → «Localização dos dados» e escolha «Migrar dados de complementos». Faça um backup antes da migração para evitar a perda de dados.

Como altero o idioma de exibição do Celestia?

Por padrão, o Celestia usa o idioma do sistema. No Android/Windows, você pode escolher outro idioma nas configurações. Nos sistemas que permitem definir o idioma de cada aplicativo (Android 13 ou posterior, iOS e macOS), você pode alterar o idioma do Celestia nas configurações do sistema. Geralmente é necessário reiniciar o Celestia para aplicar a mudança.

Como funciona a tela virtual (transmissão) no Android?

A partir da versão 1.9.8, o Celestia pode exibir conteúdo tanto em uma tela externa física quanto em uma tela virtual. Uma tela virtual não está conectada ao dispositivo: ela é criada pelo sistema. Isso é útil para transmitir a imagem a uma TV ou projetor. Porém, devido às diferentes implementações dos fabricantes, o Celestia pode não funcionar como esperado em todos os dispositivos. Por isso, a exibição em telas virtuais vem desativada por padrão; você pode ativá-la nas configurações.
Se você usa o Google Cast, um problema no GMS Cast Receiver faz com que telas virtuais inválidas sejam oferecidas ao Celestia para transmissão. Para garantir uma transmissão confiável, inicie-a antes de abrir o Celestia. Depois de encerrar uma sessão de transmissão, talvez seja necessário reiniciar o Android para remover as telas virtuais inválidas.
