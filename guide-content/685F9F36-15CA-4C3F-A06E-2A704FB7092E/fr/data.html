Vous trouverez ici les réponses aux questions les plus fréquentes sur Celestia. Celestia dispose également d’une page Wikibooks proposant des ressources supplémentaires.

Comment enrichir le contenu de Celestia ?

Celestia prend en charge les modules complémentaires : du contenu créé par la communauté pour enrichir Celestia. Pour savoir où les trouver et comment les utiliser, consultez Utiliser les extensions et les scripts.

Comment modifier la configuration ou les données de Celestia ?

Vous ne pouvez pas modifier directement le fichier celestia.cfg ni le répertoire de données par défaut, car le répertoire du paquet de l’application n’est pas accessible en écriture dans les versions modernes de Celestia. Le guide Dossier de données personnalisé explique toutefois comment démarrer Celestia avec votre propre fichier celestia.cfg et votre dossier de données plutôt qu’avec ceux par défaut.

Je souhaite créer mes propres modules complémentaires. Par où commencer ?

Consultez Créer une extension pour apprendre à créer vos propres modules.

Comment télécharger tous les modules complémentaires disponibles sur celestia.mobi ?

Celestia ne permet pas de télécharger plusieurs modules complémentaires à la fois, et nous ne recommandons pas d’essayer de le faire.
Certains modules peuvent entrer en conflit avec d’autres et empêcher Celestia de démarrer ou de fonctionner correctement. Un trop grand nombre de modules ralentit aussi considérablement Celestia.

Comment signaler une erreur dans les données de Celestia ou dans l’application ?

Si vous constatez une erreur dans un module complémentaire, ouvrez un ticket sur celestiamobile/celestia-addon-validator.
Si l’erreur concerne les données fournies avec Celestia et non un module, ouvrez un ticket sur CelestiaProject/CelestiaContent.
Pour signaler un problème du programme lui-même, utilisez « Envoyer des commentaires » → « Signaler un bug » ou « Aide » → « Signaler un bug » dans l’application.

Pourquoi ne puis-je pas trouver un certain objet astronomique dans Celestia ?

Les données de l’application Celestia ne sont pas à jour. C’est généralement la raison pour laquelle un objet mentionné dans l’actualité est introuvable. La communauté a peut-être créé un module pour cet objet : parcourez les modules disponibles en ligne. De plus, la recherche de Celestia ne porte que sur les étoiles, les objets du ciel profond et les objets du système le plus proche. Vous devrez peut-être d’abord vous rendre dans le système de l’objet.

Comment accéder au dossier des modules complémentaires sous Android 11 ou ultérieur ?

Par défaut, les modules sont installés dans Android/data. Android 11 rend l’accès à ce dossier difficile pour les gestionnaires de fichiers. Celestia 1.7.8 ou ultérieur permet toutefois d’utiliser Android/media comme dossier par défaut des modules.
Pour changer ce dossier, ouvrez « Paramètres » → « Emplacement des données » et choisissez « Migrer les données des modules complémentaires ». Faites une sauvegarde avant la migration pour éviter toute perte de données.

Comment changer la langue d’affichage de Celestia ?

Par défaut, Celestia utilise la langue du système. Sous Android/Windows, vous pouvez choisir une autre langue dans les paramètres. Sur les systèmes permettant de choisir la langue de chaque application (Android 13 ou ultérieur, iOS et macOS), vous pouvez modifier celle de Celestia dans les paramètres du système. Il faut généralement relancer Celestia pour appliquer le changement.

Comment fonctionne l’écran virtuel (diffusion) sous Android ?

À partir de la version 1.9.8, Celestia peut afficher son contenu sur un écran externe physique ou sur un écran virtuel. Un écran virtuel n’est pas connecté à l’appareil : il est créé par le système. Cela permet notamment de diffuser l’image sur un téléviseur ou un projecteur. Les fabricants implémentent toutefois la diffusion de différentes manières, et Celestia peut ne pas fonctionner comme prévu sur tous les appareils. L’affichage sur les écrans virtuels est donc désactivé par défaut ; vous pouvez l’activer dans les paramètres.
Avec Google Cast, un problème de GMS Cast Receiver propose à Celestia des écrans virtuels non valides pour la diffusion. Pour garantir une diffusion fiable, commencez-la avant de lancer Celestia. Après avoir interrompu une session de diffusion, vous devrez peut-être redémarrer Android pour supprimer les écrans virtuels non valides.
