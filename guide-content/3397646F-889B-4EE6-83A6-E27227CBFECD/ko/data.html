기본 탐색

Celestia는 다른 Xbox 앱과 동일한 탐색 방식을 사용합니다. UI 오버레이가 활성화되면(예를 들어 대화 상자를 열거나 메뉴 버튼으로 메뉴를 활성화한 경우) 스틱이나 방향 패드로 버튼 사이를 이동할 수 있습니다. A 버튼을 누르면 일반적으로 선택된 버튼의 동작이 실행됩니다. B 버튼을 누르면 일반적으로 대화 상자나 오버레이가 닫힙니다.

게임 컨트롤러 동작

기존 Win32용 Celestia는 게임 컨트롤러 지원이 제한적이지만, 이 앱에서는 더 많은 컨트롤러 버튼 동작과 기능을 추가했습니다. 게임 컨트롤러 동작 목록은 여기에서 확인할 수 있습니다. 버튼과 스틱의 동작을 사용자화하려면 다음 단계를 따르세요.

메뉴/선택 버튼을 눌러 메뉴를 여세요

파일로 이동한 다음 설정으로 이동하세요

A 버튼으로 설정을 열고, 주요 콘텐츠로 이동한 다음 A 버튼을 눌러 들어가세요

게임 컨트롤러 탭으로 이동하세요. ... 안에 숨겨져 있을 수 있습니다

설정 항목으로 이동하여 원하는 대로 동작을 변경하세요

완료되면 B 버튼을 눌러 돌아가세요

자유 비행 모드

게임 컨트롤러를 사용하면 Celestia의 자유 비행 모드로 탐험할 수 있습니다. 설정은 탐색 → 비행 모드에 있습니다. 비행 모드에 관한 자세한 내용은 여기를 참고하세요.

기본 탐색

천체를 바라보며 손가락 끝을 맞대어 탭하면 해당 천체를 선택할 수 있습니다. 손가락 끝을 맞댄 채 드래그하면 카메라의 시야가 이동합니다. 양손으로 핀치 동작을 하면 선택한 천체와의 거리를 변경할 수 있습니다.

게임 컨트롤러 동작

visionOS용 Celestia는 게임 컨트롤러를 연결하면 더 편리하게 사용할 수 있습니다. 설정 → 게임 컨트롤러에서 컨트롤러 동작을 확인하고 사용자화할 수 있습니다. 게임 컨트롤러 동작 목록은 여기를 참고하세요.

자유 비행 모드

게임 컨트롤러를 연결하면 Celestia의 자유 비행 모드로 탐험할 수 있습니다. 설정은 카메라 제어 → 비행 모드에 있습니다. 비행 모드에 관한 자세한 내용은 여기를 참고하세요.

시간 및 이동 속도 제어

대시보드 하단의 동작 버튼으로 시간과 이동 속도를 제어할 수 있습니다. 시간 제어에서는 ⏪와 ⏩를 탭할 때마다 시간의 진행 속도가 10배 단위로 변경됩니다. 이동 속도 제어에서는 ⏪와 ⏩를 길게 누르세요.

베타

Quest용 Celestia는 현재 베타 버전입니다. 기능과 동작은 변경될 수 있습니다.

오버레이

Celestia에는 주요 기능에 접근할 수 있는 2D 오버레이가 있습니다. 오버레이 내부나 아래에 있는 뒤로 버튼으로 이전 페이지로 돌아갈 수 있습니다. 오버레이를 닫은 경우 컨트롤러의 메뉴 버튼으로 다시 열 수 있습니다.

게임 컨트롤러

게임 컨트롤러 지원은 아직 개발 중입니다. 게임 컨트롤러를 사용하려면 먼저 오버레이를 닫아야 합니다. Quest 컨트롤러만 테스트되었으며 일부 기능만 지원됩니다.

자유 비행 모드

게임 컨트롤러를 연결하면 Celestia의 자유 비행 모드로 탐험할 수 있습니다. 설정은 카메라 제어 → 비행 모드에 있습니다. 비행 모드에 관한 자세한 내용은 여기를 참고하세요.

시간 및 이동 속도 제어

대시보드 하단의 동작 버튼으로 시간과 이동 속도를 제어할 수 있습니다. 시간 제어에서는 ‘더 빠르게’와 ‘더 느리게’를 탭할 때마다 시간의 진행 속도가 10배 단위로 변경됩니다. 이동 속도 제어에서는 ‘더 빠르게’와 ‘더 느리게’를 길게 누르세요.
