O novo Celestia

Android

O melhor lugar para obter o Celestia para Android é o Google Play.

O Celestia para Android também está disponível como arquivo APK para download no GitHub.

Se você não tem o Google Play, pode obter o Celestia em outras lojas de aplicativos. Algumas funcionalidades podem variar entre as versões distribuídas em lojas diferentes.

Baixe na vivo App Store

iOS/macOS

O Celestia para iOS/iPadOS/macOS está disponível na App Store.

Você também pode baixar o Celestia para macOS diretamente do GitHub.

Meta Quest

O Celestia para Meta Quest está disponível na Meta Quest Store para Meta Quest 2/3/3S/Pro.

visionOS

O Celestia para visionOS está disponível exclusivamente na App Store.

Windows/Xbox

O Celestia para Windows/Xbox está disponível na Microsoft Store.

Você também pode instalar manualmente, fora da loja, a versão disponível no GitHub.

Web/navegador

Ainda não quer instalar o Celestia no seu dispositivo? Você pode experimentar uma versão leve do Celestia no navegador.

Celestia (1.7.0)

Todas as variantes do Celestia acima são desenvolvidas a partir da versão 1.7.0 do projeto original do Celestia. Você pode obter um instalador de compilação noturna para Windows do Celestia original 1.7.0 no GitHub.

Celestia (1.6.x)

A versão estável mais recente do projeto original do Celestia (série 1.6.x) é a 1.6.4, lançada em novembro de 2023. Ela está disponível para Linux (código-fonte), macOS e Windows.
