新しい Celestia

Android

Android 版 Celestia は Google Play からの入手をおすすめします。

Android 版 Celestia は APK ファイルとしても提供されており、GitHub からダウンロードできます。

Google Play がない場合は、ほかのアプリストアから Celestia を入手できます。配信するストアによって一部の機能が異なる場合があります。

vivo App Store からダウンロード

iOS/macOS

iOS/iPadOS/macOS 版 Celestia は App Store で提供されています。

macOS 版 Celestia は GitHub から直接ダウンロードすることもできます。

Meta Quest

Meta Quest 版 Celestia は、Meta Quest 2/3/3S/Pro 向けに Meta Quest Store で提供されています。

visionOS

visionOS 版 Celestia は App Store でのみ提供されています。

Windows/Xbox

Windows/Xbox 版 Celestia は Microsoft Store で提供されています。

GitHub で提供されているバージョンを、ストアを使わずに手動でインストールすることもできます。

Web／ブラウザ

まだデバイスに Celestia をインストールしたくない場合は、ブラウザで Celestia の軽量版を試せます。

Celestia (1.7.0)

上記の Celestia の各バージョンは、オリジナルの Celestia プロジェクトのバージョン 1.7.0 を基に開発されています。オリジナルの Celestia 1.7.0 の Windows 向けナイトリービルドのインストーラーは、GitHub から入手できます。

Celestia (1.6.x)

オリジナルの Celestia プロジェクト（1.6.x 系列）の最新安定版は、2023 年 11 月にリリースされた 1.6.4 です。Linux（ソースコード）、macOS、Windows 向けに提供されています。
