新版 Celestia

Android

建議從 Google Play 取得 Android 版 Celestia。

Android 版 Celestia 也提供 APK 檔案，可從 GitHub 下載。

如果沒有 Google Play，你也可以從其他應用程式商店取得 Celestia。請注意，不同商店提供的 Celestia 版本可能存在一些功能差異。

在 vivo 應用程式商店下載

iOS/macOS

iOS/iPadOS/macOS 版 Celestia 可從 App Store 取得。

你也可以直接從 GitHub 下載 macOS 版 Celestia。

Meta Quest

Meta Quest 版 Celestia 可從 Meta Quest Store 取得，支援 Meta Quest 2/3/3S/Pro。

visionOS

visionOS 版 Celestia 僅在 App Store 提供。

Windows/Xbox

Windows/Xbox 版 Celestia 可從 Microsoft Store 取得。

你也可以使用 GitHub 提供的版本，在應用程式商店之外手動安裝。

網頁／瀏覽器

還不想在裝置上安裝 Celestia？你可以在瀏覽器中試用 Celestia 的輕量版。

Celestia (1.7.0)

以上所有 Celestia 版本均以原始 Celestia 專案的 1.7.0 版本為基礎開發。你可以從 GitHub 取得原始 Celestia 1.7.0 的 Windows 每夜建置版安裝程式。

Celestia (1.6.x)

原始 Celestia 專案（1.6.x 系列）的最新穩定版為 1.6.4，於 2023 年 11 月發布。提供 Linux（原始碼）、macOS 和 Windows 版本。
