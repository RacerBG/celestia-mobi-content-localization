Le nouveau Celestia

Android

Google Play est le meilleur endroit pour obtenir Celestia pour Android.

Celestia pour Android est aussi disponible sous forme de fichier APK à télécharger sur GitHub.

Si vous n’avez pas Google Play, vous pouvez obtenir Celestia dans d’autres boutiques d’applications. Certaines fonctionnalités peuvent différer selon la boutique qui distribue Celestia.

Télécharger sur vivo App Store

iOS/macOS

Celestia pour iOS/iPadOS/macOS est disponible dans l’App Store.

Vous pouvez aussi télécharger Celestia pour macOS directement sur GitHub.

Meta Quest

Celestia pour Meta Quest est disponible sur Meta Quest Store pour Meta Quest 2/3/3S/Pro.

visionOS

Celestia pour visionOS est disponible exclusivement dans l’App Store.

Windows/Xbox

Celestia pour Windows/Xbox est disponible dans le Microsoft Store.

Vous pouvez aussi installer hors de la boutique la version proposée sur GitHub.

Web/navigateur

Vous ne souhaitez pas encore installer Celestia sur votre appareil ? Essayez une version allégée de Celestia dans votre navigateur.

Celestia (1.7.0)

Toutes les variantes de Celestia ci-dessus sont développées à partir de la version 1.7.0 du projet Celestia original. Un programme d’installation Windows issu d’une compilation nocturne de Celestia 1.7.0 original est disponible sur GitHub.

Celestia (1.6.x)

La dernière version stable du projet Celestia original (série 1.6.x) est la version 1.6.4, publiée en novembre 2023. Elle est disponible pour Linux (code source), macOS et Windows.
