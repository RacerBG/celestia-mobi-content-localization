Новая Celestia

Android

Celestia для Android лучше всего скачивать в Google Play.

Celestia для Android также доступна в виде APK-файла, который можно скачать на GitHub.

Если у вас нет Google Play, Celestia можно получить в других магазинах приложений. Учтите, что функции версий, распространяемых в разных магазинах, могут отличаться.

Скачать в vivo App Store

iOS/macOS

Celestia для iOS/iPadOS/macOS доступна в App Store.

Celestia для macOS также можно скачать непосредственно с GitHub.

Meta Quest

Celestia для Meta Quest доступна в Meta Quest Store для Meta Quest 2/3/3S/Pro.

visionOS

Celestia для visionOS распространяется исключительно через App Store.

Windows/Xbox

Celestia для Windows/Xbox доступна в Microsoft Store.

Можно также установить приложение вручную, вне магазина, используя версию с GitHub.

Веб/браузер

Пока не хотите устанавливать Celestia на устройство? Попробуйте облегчённую версию Celestia в браузере.

Celestia (1.7.0)

Все перечисленные выше варианты Celestia разработаны на основе версии 1.7.0 исходного проекта Celestia. Установщик ночной сборки исходной Celestia 1.7.0 для Windows можно получить на GitHub.

Celestia (1.6.x)

Последний стабильный выпуск исходного проекта Celestia (серия 1.6.x) — версия 1.6.4, выпущенная в ноябре 2023 года. Она доступна для Linux (исходный код), macOS и Windows.
