Das neue Celestia

Android

Celestia für Android erhältst du am besten bei Google Play.

Celestia für Android ist auch als APK-Datei verfügbar, die du auf GitHub herunterladen kannst.

Wenn du Google Play nicht hast, kannst du Celestia auch aus anderen App-Stores beziehen. Beachte, dass sich der Funktionsumfang der in verschiedenen Stores angebotenen Versionen unterscheiden kann.

Im vivo App Store herunterladen

iOS/macOS

Celestia für iOS/iPadOS/macOS ist im App Store verfügbar.

Du kannst Celestia für macOS auch direkt von GitHub herunterladen.

Meta Quest

Celestia für Meta Quest ist im Meta Quest Store für Meta Quest 2/3/3S/Pro verfügbar.

visionOS

Celestia für visionOS ist ausschließlich im App Store verfügbar.

Windows/Xbox

Celestia für Windows/Xbox ist im Microsoft Store verfügbar.

Du kannst auch die auf GitHub bereitgestellte Version außerhalb des Stores installieren.

Web/Browser

Du möchtest Celestia noch nicht auf deinem Gerät installieren? Du kannst eine schlanke Version von Celestia in deinem Browser ausprobieren.

Celestia (1.7.0)

Alle oben aufgeführten Varianten von Celestia basieren auf Version 1.7.0 des ursprünglichen Celestia-Projekts. Einen Nightly-Installer für Windows der ursprünglichen Version Celestia 1.7.0 findest du auf GitHub.

Celestia (1.6.x)

Die neueste stabile Veröffentlichung des ursprünglichen Celestia-Projekts (Reihe 1.6.x) ist Version 1.6.4, erschienen im November 2023. Sie ist für Linux (Quellcode), macOS und Windows verfügbar.
