新版 Celestia

Android

建议从 Google Play 获取 Android 版 Celestia。

Android 版 Celestia 也提供 APK 文件，可从 GitHub 下载。

如果没有 Google Play，你也可以从其他应用商店获取 Celestia。请注意，不同商店提供的 Celestia 版本可能存在一些功能差异。

在 vivo 应用商店下载

iOS/macOS

iOS/iPadOS/macOS 版 Celestia 可从 App Store 获取。

你也可以直接从 GitHub 下载 macOS 版 Celestia。

Meta Quest

Meta Quest 版 Celestia 可从 Meta Quest Store 获取，支持 Meta Quest 2/3/3S/Pro。

visionOS

visionOS 版 Celestia 仅在 App Store 提供。

Windows/Xbox

Windows/Xbox 版 Celestia 可从 Microsoft Store 获取。

你也可以使用 GitHub 提供的版本，在应用商店之外手动安装。

网页／浏览器

还不想在设备上安装 Celestia？你可以在浏览器中试用 Celestia 的轻量版。

Celestia (1.7.0)

以上所有 Celestia 版本均基于原始 Celestia 项目的 1.7.0 版本开发。你可以从 GitHub 获取原始 Celestia 1.7.0 的 Windows 每夜构建版安装程序。

Celestia (1.6.x)

原始 Celestia 项目（1.6.x 系列）的最新稳定版为 1.6.4，于 2023 年 11 月发布。提供 Linux（源代码）、macOS 和 Windows 版本。
