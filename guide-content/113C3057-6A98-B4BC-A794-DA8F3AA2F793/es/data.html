El nuevo Celestia

Android

El mejor lugar para obtener Celestia para Android es Google Play.

Celestia para Android también está disponible como archivo APK que puedes descargar en GitHub.

Si no tienes Google Play, también puedes obtener Celestia en tiendas alternativas. Ten en cuenta que las funciones pueden variar entre las versiones distribuidas en distintas tiendas.

Descargar en vivo App Store

iOS/macOS

Celestia para iOS/iPadOS/macOS está disponible en el App Store.

También puedes descargar Celestia para macOS directamente desde GitHub.

Meta Quest

Celestia para Meta Quest está disponible en Meta Quest Store para Meta Quest 2/3/3S/Pro.

visionOS

Celestia para visionOS está disponible exclusivamente en el App Store.

Windows/Xbox

Celestia para Windows/Xbox está disponible en Microsoft Store.

También puedes instalar fuera de la tienda la versión disponible en GitHub.

Web/navegador

¿Aún no quieres instalar Celestia en tu dispositivo? Puedes probar una versión ligera de Celestia en tu navegador.

Celestia (1.7.0)

Todas las variantes de Celestia anteriores se desarrollan a partir de la versión 1.7.0 del proyecto original de Celestia. Puedes obtener un instalador de compilación nocturna para Windows del Celestia original 1.7.0 en GitHub.

Celestia (1.6.x)

La última versión estable del proyecto original de Celestia (serie 1.6.x) es la 1.6.4, publicada en noviembre de 2023. Está disponible para Linux (código fuente), macOS y Windows.
