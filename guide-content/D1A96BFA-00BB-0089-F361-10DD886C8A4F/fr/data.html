Installer Celestia

Obtenez la dernière version de Celestia ici.

Si l’extension est hébergée sur celestia.mobi et que votre version de Celestia permet de l’ouvrir directement, cliquez sur « Ouvrir dans Celestia » sur la page web.

Si vous téléchargez les extensions manuellement ou que votre version de Celestia ne permet pas de les ouvrir directement, poursuivez la lecture.

Utiliser le dossier d’extensions par défaut (recommandé)

Celestia charge les extensions et les scripts supplémentaires depuis des dossiers précis. Sur les plateformes suivantes, le dossier principal s’appelle « CelestiaResources » et contient « extras » pour les extensions et « scripts » pour les scripts supplémentaires.

iOS/iPadOS

Le dossier se trouve dans le dossier partagé de l’application. Pour afficher son contenu :

  1. Lancez Celestia au moins une fois.
  2. Ouvrez l’application Fichiers.
  3. Allez dans l’onglet Explorer.
  4. Touchez « Sur mon iPhone » ou « Sur mon iPad » dans la liste.
  5. Recherchez Celestia et ouvrez son dossier.

Il devrait contenir un dossier CelestiaResources.

Android

Le dossier se trouve dans le répertoire externe de l’application : Android/data/space.celestia.mobilecelestia/files/CelestiaResources.

Sur Android 11 ou ultérieur, ce dossier peut être invisible. Vous pouvez alors aller dans Android/media/space.celestia.mobilecelestia et créer vous-même les dossiers CelestiaResources/extras et CelestiaResources/scripts.

Vous pouvez modifier l’emplacement d’installation des extensions dans Réglages -> Emplacement des données.

Mac (Catalyst)

Le dossier se trouve dans /Users/YOUR USER NAME HERE/Library/Containers/space.celestia.MobileCelestia/Data/Documents/CelestiaResources.

Remplacez « YOUR USER NAME HERE » par votre nom d’utilisateur. Vous pouvez aussi l’ouvrir dans l’application via Outils, Ouvrir le dossier des extensions.

Mac (ancienne version)

Le dossier se trouve dans /Users/YOUR USER NAME HERE/Library/Containers/space.celestia.Celestia/Data/Documents/CelestiaResources.

Remplacez « YOUR USER NAME HERE » par votre nom d’utilisateur.

Windows (Microsoft Store)

  1. Lancez Celestia.
  2. Fichier -> Ouvrir le dossier personnalisé

Le dossier CelestiaResources devrait s’y trouver. Son chemin ressemble à C:\Users\YOUR USER NAME HERE\AppData\Local\Packages\40507LinfengLi.Celestia_r7f2qt5a05s84\LocalState\CelestiaResources. Remplacez « YOUR USER NAME HERE » par votre nom d’utilisateur. Vous pouvez aussi l’ouvrir via Outils, Ouvrir le dossier des extensions dans l’application.

Windows (ancienne version)

Les dossiers « extras » et « scripts » se trouvent dans le dossier d’installation de Celestia, généralement C:\Program Files (x86)\Celestia ou C:\Program Files\Celestia.

Indiquer un dossier de données

Pour une personnalisation complète, consultez Remplacer le dossier de données.
