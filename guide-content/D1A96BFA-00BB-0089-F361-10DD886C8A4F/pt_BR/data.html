Instalar o Celestia

Você pode obter a versão mais recente do Celestia aqui.

Se o complemento estiver em celestia.mobi e sua versão do Celestia permitir abri-lo diretamente, clique em «Abrir no Celestia» na página.

Se você baixar complementos manualmente ou sua versão não permitir abri-los diretamente, continue lendo.

Usar a pasta padrão de complementos (recomendado)

O Celestia lê complementos e scripts adicionais de pastas específicas. Nas plataformas abaixo, a pasta principal se chama «CelestiaResources» e contém «extras» para complementos e «scripts» para scripts adicionais.

iOS/iPadOS

A pasta fica no diretório compartilhado do aplicativo. Para ver seu conteúdo:

  1. Execute o Celestia pelo menos uma vez.
  2. Abra o aplicativo Arquivos.
  3. Vá para a aba Explorar.
  4. Toque em «No Meu iPhone» ou «No Meu iPad» na lista.
  5. Encontre o Celestia e abra sua pasta.

Deve haver uma pasta CelestiaResources dentro dela.

Android

A pasta fica no diretório externo do aplicativo: Android/data/space.celestia.mobilecelestia/files/CelestiaResources.

No Android 11 ou posterior, talvez essa pasta não fique visível. Você pode ir a Android/media/space.celestia.mobilecelestia e criar manualmente CelestiaResources/extras e CelestiaResources/scripts.

Você pode alterar onde os complementos são instalados em Configurações -> Localização dos dados.

Mac (Catalyst)

A pasta fica em /Users/YOUR USER NAME HERE/Library/Containers/space.celestia.MobileCelestia/Data/Documents/CelestiaResources.

Substitua «YOUR USER NAME HERE» pelo seu nome de usuário. Também é possível abrir a pasta pelo aplicativo em Ferramentas, Abrir pasta de complementos.

Mac (versão clássica)

A pasta fica em /Users/YOUR USER NAME HERE/Library/Containers/space.celestia.Celestia/Data/Documents/CelestiaResources.

Substitua «YOUR USER NAME HERE» pelo seu nome de usuário.

Windows (Microsoft Store)

  1. Execute o Celestia.
  2. Arquivo -> Abrir pasta personalizada

A pasta CelestiaResources deve estar ali. O caminho será parecido com C:\Users\YOUR USER NAME HERE\AppData\Local\Packages\40507LinfengLi.Celestia_r7f2qt5a05s84\LocalState\CelestiaResources. Substitua «YOUR USER NAME HERE» pelo seu nome de usuário. Você também pode abri-la pelo aplicativo em Ferramentas, Abrir pasta de complementos.

Windows (versão clássica)

A pasta de instalação do Celestia contém «extras» e «scripts». Por padrão, ela fica em C:\Program Files (x86)\Celestia ou C:\Program Files\Celestia.
