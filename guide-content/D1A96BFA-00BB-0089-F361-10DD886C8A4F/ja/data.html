Celestia をインストールする

最新の Celestia はこちらから入手できます。

celestia.mobi のアドオンで、利用中の Celestia が直接開く機能に対応している場合は、Web ページの「Celestia で開く」を押してください。

アドオンを手動でダウンロードする場合や、利用中のバージョンが直接開く機能に対応していない場合は、続きをお読みください。

標準のアドオンフォルダを使う（推奨）

Celestia は専用フォルダからアドオンと追加スクリプトを読み込みます。次のプラットフォームでは CelestiaResources 内に、アドオン用の extras と追加スクリプト用の scripts があります。

iOS/iPadOS

フォルダはアプリの共有フォルダ内にあります。次の手順で内容を確認できます。

  1. Celestia を一度以上起動します。
  2. 「ファイル」アプリを開きます。
  3. 「ブラウズ」タブを開きます。
  4. 一覧の「この iPhone 内」または「この iPad 内」を選びます。
  5. Celestia を探して開きます。

その中に CelestiaResources フォルダがあります。

Android

フォルダはアプリの外部領域 Android/data/space.celestia.mobilecelestia/files/CelestiaResources にあります。

Android 11 以降では、このフォルダが表示されない場合があります。その場合は Android/media/space.celestia.mobilecelestia 内に CelestiaResources/extras と CelestiaResources/scripts を自分で作成できます。

アドオンのインストール先は、設定 -> データの場所で変更できます。

Mac（Catalyst）

フォルダは /Users/YOUR USER NAME HERE/Library/Containers/space.celestia.MobileCelestia/Data/Documents/CelestiaResources にあります。

YOUR USER NAME HERE を実際のユーザー名に置き換えてください。アプリ内のツール、アドオンフォルダを開くからもアクセスできます。

Mac（従来版）

フォルダは /Users/YOUR USER NAME HERE/Library/Containers/space.celestia.Celestia/Data/Documents/CelestiaResources にあります。

YOUR USER NAME HERE を実際のユーザー名に置き換えてください。

Windows（Microsoft Store）

  1. Celestia を起動します。
  2. ファイル -> カスタムフォルダを開く

開いた場所に CelestiaResources があります。パスは C:\Users\YOUR USER NAME HERE\AppData\Local\Packages\40507LinfengLi.Celestia_r7f2qt5a05s84\LocalState\CelestiaResources のようになります。YOUR USER NAME HERE を実際のユーザー名に置き換えてください。アプリ内のツール、アドオンフォルダを開くからもアクセスできます。

Windows（従来版）

Celestia のインストール先に extras と scripts フォルダがあります。標準のインストール先は C:\Program Files (x86)\Celestia または C:\Program Files\Celestia です。

データの読み込み元を指定する

完全なカスタマイズについてはデータの読み込み元フォルダを変更するを参照してください。
