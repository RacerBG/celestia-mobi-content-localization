Installare Celestia

Puoi ottenere l’ultima versione di Celestia qui.

Se il componente aggiuntivo è ospitato su celestia.mobi e la tua versione di Celestia supporta l’apertura diretta, premi «Apri in Celestia» nella pagina web.

Se scarichi i componenti aggiuntivi manualmente o la tua versione di Celestia non supporta l’apertura diretta, continua a leggere.

Usare la cartella predefinita dei componenti aggiuntivi (consigliato)

Celestia legge i componenti aggiuntivi e gli script aggiuntivi da cartelle specifiche. Nelle piattaforme seguenti la cartella principale si chiama «CelestiaResources» e contiene «extras» per i componenti aggiuntivi e «scripts» per gli script aggiuntivi.

iOS/iPadOS

La cartella si trova nel percorso condiviso dell’app. Per visualizzarne il contenuto:

  1. Avvia Celestia almeno una volta.
  2. Apri l’app File.
  3. Vai alla scheda Sfoglia.
  4. Premi «Su iPhone» o «Su iPad» nell’elenco.
  5. Trova Celestia e apri la sua cartella.

Al suo interno dovrebbe esserci una cartella CelestiaResources.

Android

La cartella è nel percorso esterno dell’app: Android/data/space.celestia.mobilecelestia/files/CelestiaResources.

Su Android 11 e successivi potresti non vedere quella cartella. Puoi invece andare in Android/media/space.celestia.mobilecelestia e creare manualmente CelestiaResources/extras e CelestiaResources/scripts.

Puoi cambiare la posizione di installazione dei componenti aggiuntivi in Impostazioni -> Posizione dei dati.

Mac (Catalyst)

La cartella si trova in /Users/YOUR USER NAME HERE/Library/Containers/space.celestia.MobileCelestia/Data/Documents/CelestiaResources.

Sostituisci «YOUR USER NAME HERE» con il tuo nome utente. Puoi aprire la cartella anche dall’app con Strumenti, Apri cartella dei componenti aggiuntivi.

Mac (versione classica)

La cartella si trova in /Users/YOUR USER NAME HERE/Library/Containers/space.celestia.Celestia/Data/Documents/CelestiaResources.

Sostituisci «YOUR USER NAME HERE» con il tuo nome utente.

Windows (Microsoft Store)

  1. Avvia Celestia.
  2. File -> Apri cartella personalizzata

La cartella CelestiaResources dovrebbe trovarsi lì. Il percorso sarà simile a C:\Users\YOUR USER NAME HERE\AppData\Local\Packages\40507LinfengLi.Celestia_r7f2qt5a05s84\LocalState\CelestiaResources. Sostituisci «YOUR USER NAME HERE» con il tuo nome utente. Puoi aprirla anche dall’app con Strumenti, Apri cartella dei componenti aggiuntivi.

Windows (versione classica)

La cartella di installazione di Celestia contiene «extras» e «scripts». Il percorso predefinito è C:\Program Files (x86)\Celestia o C:\Program Files\Celestia.
