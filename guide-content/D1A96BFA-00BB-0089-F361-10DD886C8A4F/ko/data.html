Celestia 설치하기

최신 Celestia는 여기에서 받을 수 있습니다.

celestia.mobi에 있는 애드온이고 사용하는 Celestia 버전이 직접 열기를 지원한다면 웹페이지에서 'Celestia에서 열기'를 누르세요.

애드온을 직접 다운로드하거나 사용하는 버전이 직접 열기를 지원하지 않는다면 계속 읽어 주세요.

기본 애드온 폴더 사용하기(권장)

Celestia는 지정된 폴더에서 애드온과 추가 스크립트를 읽습니다. 다음 플랫폼에서는 CelestiaResources 폴더 안에 애드온용 extras와 추가 스크립트용 scripts 폴더가 있습니다.

iOS/iPadOS

폴더는 앱의 공유 폴더에 있습니다. 다음과 같이 내용을 확인할 수 있습니다.

  1. Celestia를 한 번 이상 실행하세요.
  2. 파일 앱을 여세요.
  3. 둘러보기 탭으로 이동하세요.
  4. 목록에서 '나의 iPhone' 또는 '나의 iPad'를 누르세요.
  5. Celestia를 찾아 여세요.

그 안에 CelestiaResources 폴더가 있어야 합니다.

Android

폴더는 앱의 외부 경로 Android/data/space.celestia.mobilecelestia/files/CelestiaResources에 있습니다.

Android 11 이상에서는 이 폴더가 보이지 않을 수 있습니다. 이 경우 Android/media/space.celestia.mobilecelestia 아래에 CelestiaResources/extras와 CelestiaResources/scripts를 직접 만들 수 있습니다.

설정 -> 데이터 위치에서 애드온 설치 위치를 변경할 수 있습니다.

Mac(Catalyst)

폴더는 /Users/YOUR USER NAME HERE/Library/Containers/space.celestia.MobileCelestia/Data/Documents/CelestiaResources에 있습니다.

YOUR USER NAME HERE를 실제 사용자 이름으로 바꾸세요. 앱 안에서 도구, 애드온 폴더 열기를 선택해 열 수도 있습니다.

Mac(기존 버전)

폴더는 /Users/YOUR USER NAME HERE/Library/Containers/space.celestia.Celestia/Data/Documents/CelestiaResources에 있습니다.

YOUR USER NAME HERE를 실제 사용자 이름으로 바꾸세요.

Windows(Microsoft Store)

  1. Celestia를 실행하세요.
  2. 파일 -> 사용자 지정 폴더 열기

CelestiaResources 폴더가 그 안에 있어야 합니다. 경로는 C:\Users\YOUR USER NAME HERE\AppData\Local\Packages\40507LinfengLi.Celestia_r7f2qt5a05s84\LocalState\CelestiaResources와 비슷합니다. YOUR USER NAME HERE를 실제 사용자 이름으로 바꾸세요. 앱 안의 도구, 애드온 폴더 열기에서도 열 수 있습니다.

Windows(기존 버전)

Celestia 설치 폴더에 extras와 scripts 폴더가 있습니다. 기본 설치 위치는 C:\Program Files (x86)\Celestia 또는 C:\Program Files\Celestia입니다.

데이터를 읽을 폴더 지정하기

전체 사용자 지정 방법은 데이터 폴더 변경하기를 참고하세요.
