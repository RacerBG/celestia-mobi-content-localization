安裝 Celestia

在這裡可以取得最新版 Celestia。

若附加元件由 celestia.mobi 提供，且目前的 Celestia 版本支援直接開啟，請點選網頁上的「在 Celestia 中開啟」。

若手動下載附加元件，或目前的版本不支援直接開啟，請繼續閱讀。

使用預設附加元件資料夾（建議）

Celestia 從特定資料夾讀取附加元件與額外指令碼。在下列平台上，主資料夾名為 CelestiaResources，其中的 extras 用於附加元件，scripts 用於額外指令碼。

iOS/iPadOS

資料夾位於 App 的共享資料夾中，可依照以下步驟查看：

  1. 執行 Celestia 至少一次。
  2. 開啟「檔案」App。
  3. 切換至「瀏覽」標籤頁。
  4. 點選列表中的「我的 iPhone」或「我的 iPad」。
  5. 找到 Celestia 並開啟。

裡面應該有 CelestiaResources 資料夾。

Android

資料夾位於 App 的外部目錄 Android/data/space.celestia.mobilecelestia/files/CelestiaResources。

在 Android 11 及更新版本中，此資料夾可能無法看見。此時可在 Android/media/space.celestia.mobilecelestia 中自行建立 CelestiaResources/extras 和 CelestiaResources/scripts。

可在設定 -> 資料位置變更附加元件的安裝位置。

Mac（Catalyst）

資料夾位於 /Users/YOUR USER NAME HERE/Library/Containers/space.celestia.MobileCelestia/Data/Documents/CelestiaResources。

將 YOUR USER NAME HERE 替換成你的使用者名稱。也可以在 App 內選擇工具、開啟附加元件資料夾。

Mac（舊版）

資料夾位於 /Users/YOUR USER NAME HERE/Library/Containers/space.celestia.Celestia/Data/Documents/CelestiaResources。

將 YOUR USER NAME HERE 替換成你的使用者名稱。

Windows（Microsoft Store）

  1. 執行 Celestia。
  2. 檔案 -> 開啟自訂資料夾

裡面應該有 CelestiaResources 資料夾。路徑類似 C:\Users\YOUR USER NAME HERE\AppData\Local\Packages\40507LinfengLi.Celestia_r7f2qt5a05s84\LocalState\CelestiaResources。請將 YOUR USER NAME HERE 替換成你的使用者名稱。也可在 App 內選擇工具、開啟附加元件資料夾。

Windows（舊版）

Celestia 的安裝目錄中有 extras 和 scripts 資料夾。預設安裝路徑是 C:\Program Files (x86)\Celestia 或 C:\Program Files\Celestia。
