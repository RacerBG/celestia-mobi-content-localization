Установка Celestia

Последнюю версию Celestia можно получить здесь.

Если дополнение размещено на celestia.mobi и ваша версия поддерживает его прямое открытие, нажмите «Открыть в Celestia» на веб-странице.

Если вы загружаете дополнения вручную или ваша версия не поддерживает прямое открытие, читайте далее.

Используйте стандартную папку дополнений (рекомендуется)

Celestia читает дополнения и дополнительные скрипты из определённых папок. На следующих платформах основная папка называется CelestiaResources и содержит extras для дополнений и scripts для дополнительных скриптов.

iOS/iPadOS

Папка находится в общей папке приложения. Чтобы посмотреть её содержимое:

  1. Запустите Celestia хотя бы один раз.
  2. Откройте приложение «Файлы».
  3. Перейдите на вкладку «Обзор».
  4. Выберите в списке «На моём iPhone» или «На моём iPad».
  5. Найдите Celestia и откройте её папку.

Внутри должна находиться папка CelestiaResources.

Android

Папка находится во внешнем каталоге приложения: Android/data/space.celestia.mobilecelestia/files/CelestiaResources.

На Android 11 и новее эта папка может быть недоступна. Вместо неё можно открыть Android/media/space.celestia.mobilecelestia и вручную создать CelestiaResources/extras и CelestiaResources/scripts.

Место установки дополнений можно изменить в Настройки -> Расположение данных.

Mac (Catalyst)

Папка находится в /Users/YOUR USER NAME HERE/Library/Containers/space.celestia.MobileCelestia/Data/Documents/CelestiaResources.

Замените YOUR USER NAME HERE своим именем пользователя. Папку также можно открыть в приложении через Инструменты, Открыть папку дополнений.

Mac (старая версия)

Папка находится в /Users/YOUR USER NAME HERE/Library/Containers/space.celestia.Celestia/Data/Documents/CelestiaResources.

Замените YOUR USER NAME HERE своим именем пользователя.

Windows (Microsoft Store)

  1. Запустите Celestia.
  2. Файл -> Открыть пользовательскую папку

Там должна находиться папка CelestiaResources. Её путь выглядит примерно так: C:\Users\YOUR USER NAME HERE\AppData\Local\Packages\40507LinfengLi.Celestia_r7f2qt5a05s84\LocalState\CelestiaResources. Замените YOUR USER NAME HERE своим именем пользователя. Также её можно открыть в приложении через Инструменты, Открыть папку дополнений.

Windows (старая версия)

В папке установки Celestia находятся extras и scripts. По умолчанию путь установки — C:\Program Files (x86)\Celestia или C:\Program Files\Celestia.
