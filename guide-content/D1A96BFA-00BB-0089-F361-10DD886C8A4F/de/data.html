Celestia installieren

Die neueste Version von Celestia erhältst du hier.

Wenn das Add-on auf celestia.mobi angeboten wird und deine Celestia-Version das direkte Öffnen unterstützt, klicke auf der Webseite auf „In Celestia öffnen“.

Wenn du Add-ons manuell herunterlädst oder deine Celestia-Version das direkte Öffnen nicht unterstützt, lies bitte weiter.

Den Standardordner für Add-ons verwenden (empfohlen)

Celestia liest Add-ons und zusätzliche Skripte aus bestimmten Ordnern. Auf den folgenden Plattformen heißt der übergeordnete Ordner „CelestiaResources“. Er enthält „extras“ für Add-ons und „scripts“ für zusätzliche Skripte.

iOS/iPadOS

Der Ordner liegt im freigegebenen App-Ordner. So kannst du seinen Inhalt anzeigen:

  1. Starte Celestia mindestens einmal.
  2. Öffne die App „Dateien“.
  3. Wechsle zum Tab „Durchsuchen“.
  4. Wähle in der Liste „Auf meinem iPhone“ beziehungsweise „Auf meinem iPad“.
  5. Suche Celestia und öffne den Eintrag.

Darin sollte sich ein Ordner namens CelestiaResources befinden.

Android

Der Ordner liegt im externen App-Verzeichnis: Android/data/space.celestia.mobilecelestia/files/CelestiaResources.

Unter Android 11 und neuer ist dieser Ordner möglicherweise nicht sichtbar. Du kannst stattdessen unter Android/media/space.celestia.mobilecelestia selbst die Ordner CelestiaResources/extras und CelestiaResources/scripts anlegen.

Den Installationsort der Add-ons kannst du unter Einstellungen -> Datenpfad ändern.

Mac (Catalyst)

Der Ordner liegt unter /Users/YOUR USER NAME HERE/Library/Containers/space.celestia.MobileCelestia/Data/Documents/CelestiaResources.

Ersetze „YOUR USER NAME HERE“ durch deinen Benutzernamen. Du kannst den Ordner auch in der App über Werkzeuge, Add-on-Ordner öffnen aufrufen.

Mac (ältere Version)

Der Ordner liegt unter /Users/YOUR USER NAME HERE/Library/Containers/space.celestia.Celestia/Data/Documents/CelestiaResources.

Ersetze „YOUR USER NAME HERE“ durch deinen Benutzernamen.

Windows (Microsoft Store)

  1. Starte Celestia.
  2. Datei -> Benutzerdefinierten Ordner öffnen

Der Ordner CelestiaResources sollte dort zu finden sein. Sein Pfad sieht etwa so aus: C:\Users\YOUR USER NAME HERE\AppData\Local\Packages\40507LinfengLi.Celestia_r7f2qt5a05s84\LocalState\CelestiaResources. Ersetze „YOUR USER NAME HERE“ durch deinen Benutzernamen. In der App kannst du den Ordner auch über Werkzeuge, Add-on-Ordner öffnen aufrufen.

Windows (ältere Version)

Im Installationsordner von Celestia liegen die Ordner „extras“ und „scripts“. Der Standardpfad ist C:\Program Files (x86)\Celestia oder C:\Program Files\Celestia.

Ein Datenverzeichnis angeben

Für eine vollständige Anpassung siehe Ein anderes Datenverzeichnis verwenden.
