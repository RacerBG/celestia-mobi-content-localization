Instalar Celestia

Puedes obtener la última versión de Celestia aquí.

Si el complemento está alojado en celestia.mobi y tu versión de Celestia admite abrirlo directamente, pulsa «Abrir en Celestia» en la página web.

Si descargas complementos manualmente o tu versión de Celestia no permite abrirlos directamente, continúa leyendo.

Usar la carpeta predeterminada de complementos (recomendado)

Celestia lee los complementos y scripts adicionales de carpetas específicas. En las plataformas siguientes, la carpeta principal se llama «CelestiaResources» y contiene «extras» para complementos y «scripts» para scripts adicionales.

iOS/iPadOS

La carpeta está en el directorio compartido de la aplicación. Para ver su contenido:

  1. Ejecuta Celestia al menos una vez.
  2. Abre la aplicación Archivos.
  3. Ve a la pestaña Explorar.
  4. Pulsa «En mi iPhone» o «En mi iPad» en la lista.
  5. Busca Celestia y abre su carpeta.

Dentro debería haber una carpeta CelestiaResources.

Android

La carpeta está en el directorio externo de la aplicación: Android/data/space.celestia.mobilecelestia/files/CelestiaResources.

En Android 11 y posteriores, puede que esa carpeta no sea visible. Puedes ir a Android/media/space.celestia.mobilecelestia y crear las carpetas CelestiaResources/extras y CelestiaResources/scripts manualmente.

Puedes cambiar dónde se instalan los complementos desde Ajustes -> Ubicación de datos.

Mac (Catalyst)

La carpeta está en /Users/YOUR USER NAME HERE/Library/Containers/space.celestia.MobileCelestia/Data/Documents/CelestiaResources.

Sustituye «YOUR USER NAME HERE» por tu nombre de usuario. También puedes abrirla desde la aplicación con Herramientas, Abrir carpeta de complementos.

Mac (versión clásica)

La carpeta está en /Users/YOUR USER NAME HERE/Library/Containers/space.celestia.Celestia/Data/Documents/CelestiaResources.

Sustituye «YOUR USER NAME HERE» por tu nombre de usuario.

Windows (Microsoft Store)

  1. Ejecuta Celestia.
  2. Archivo -> Abrir carpeta personalizada

La carpeta CelestiaResources debería estar allí. Su ruta será parecida a C:\Users\YOUR USER NAME HERE\AppData\Local\Packages\40507LinfengLi.Celestia_r7f2qt5a05s84\LocalState\CelestiaResources. Sustituye «YOUR USER NAME HERE» por tu nombre de usuario. También puedes abrirla desde Herramientas, Abrir carpeta de complementos en la aplicación.

Windows (versión clásica)

La carpeta de instalación de Celestia contiene «extras» y «scripts». Por defecto está en C:\Program Files (x86)\Celestia o C:\Program Files\Celestia.

Indicar un directorio de datos

Para una personalización completa, consulta Sustituir el directorio de datos.
